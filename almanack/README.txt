THE ALMANACK OF NAVAL RAVIKANT · animated study book (pilot: chapter 1, English + Malayalam)
A static website. No server code, no database, no build step.

LIVE ADDRESS (GitHub Pages)
   Whole book:     https://mahroofcm.github.io/ymulinks/almanack/
   Chapter 1:      https://mahroofcm.github.io/ymulinks/almanack/ch01/
   In Malayalam:   add ?lang=ml   e.g. https://mahroofcm.github.io/ymulinks/almanack/ch01/?lang=ml

WHATSAPP PREVIEW
   Every page carries og: tags pointing at og-image.png (1200 x 630).
   If you move the book to another address, replace  mahroofcm.github.io/ymulinks/almanack  in
   index.html and ch01/index.html with the new address (without https://).
   WhatsApp caches previews: a link you already sent keeps its old card; a new chat or ?v=2 at the end shows the new one.

WHAT IS INSIDE
   index.html            cover + contents
   ch01/                 lesson 1 and its narration (audio/en, audio/ml: Microsoft neural voices, -5% pace)
   lib/                  player engine, YMU element library (ymu.js), styles, self-hosted fonts (OFL, lib/fonts/OFL.txt)
   og-image.png          link preview card
